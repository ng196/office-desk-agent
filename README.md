# Office Desk Agent (working name)

An offline AI helper for a government or PSU office clerk.

## MVP (only this)
1. Drop an incoming letter (PDF or text) into the Inbox.
2. It shows a short summary and the closest past letters and rules from the office's own files.
3. It drafts an official reply in Hindi or English, where every line points to the past file or rule it came from.
4. The clerk edits the draft and presses Approve, and the reply is saved to Outbox.
5. Everything runs on this computer with no internet. Trying to send a file out is blocked, and every step is written to a log the boss can read.

## Not in MVP
Excel register, sending email, handwriting, multiple users, approval chains, voice, other languages, e-Office integration.
