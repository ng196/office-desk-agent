> **Correction (from tests.md):** for rows 6 and 7, use the hindi-font-converter `kd.js`/`ch.js` tables as the main converter, not HinLegacy. HinLegacy adds an extra halant (dk;kZy; becomes कार््यालय), its Chanakya conversion is broken in both directions, and it can't tell Kruti Dev from DevLys. Chanakya has at least 2 incompatible encodings, so detect it by font name.

## Not cleanly solved yet
1. **Legacy-font detection inside real PDFs.** Fonts are subset, renamed (e.g. `ABCDEF+KrutiDev010`) or mixed with Unicode on one page. Tools only claim detection, with no benchmark.
2. **Chanakya / DevLys conversion quality.** Several variants exist (Chanakya vs Walkman-Chanakya-905, DevLys 010 vs 020). No tested, maintained library has a public accuracy number.
3. **Hindi citation and attribution checking.** Exact quote matching works. Checking that a Hindi line is actually supported by its quote (NLI) has no off-the-shelf model.
4. **Official Hindi letter drafting on CPU-sized models (3B to 8B).** Register (राजभाषा style), honorifics and fixed phrases are weak. No benchmark exists, and Indic-specialist small models have non-commercial licences.
5. **Hindi govt-letter retrieval evaluation.** No dataset exists, so embedding and reranker choice is guesswork until we build roughly 100 labelled pairs.
6. **Mixed scanned+typed+stamped letters.** Each tool handles one mode. Routing per region is DIY.

## Top-5 risks
1. **Licences:** PyMuPDF AGPL, Surya/Marker weights (commercial limit above $5M), Sarvam-1 non-commercial, fastText-LID and jina reranker CC-BY-NC, immudb BSL. Use the Apache/MIT alternatives listed.
2. **Legacy-font text silently mis-read** becomes garbage in search and drafts. Gate every document through detection plus a sample preview for the clerk.
3. **CPU latency:** OCR, rerank and a 4 to 7B draft on one box could take minutes per letter. Benchmark on target hardware early.
4. **Draft quality in Hindi** from small models. Keep the template plus the quote-first approach, and let the LLM only fill gaps.
5. **Audit log credibility:** the admin can rewrite a local hash chain. Export daily checkpoint hashes off-box.
